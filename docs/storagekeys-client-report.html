Layout Shift Completely Fixed — CLS Score 0.227 → 0.001
✅ Complete
Cumulative Layout Shift (CLS) measures how much the page "jumps around" as it loads — this is very frustrating for users and penalised by Google. The issue was caused by the custom brand font loading from a third-party CDN after the page had already rendered, shifting all text. The font is now self-hosted on our server and loads instantly with the page.
Before — CLS 0.227 🔴Font loading from Google CDN caused text to jump. Users would accidentally tap wrong elements. Google penalty applied.
After — CLS 0.001 ✅Font self-hosted. Zero layout shift. Google "Good" threshold met. No more jumping content on mobile.
CLS 0.001Google "Good"Mobile UX Fixed

Google Analytics & reCAPTCHA Deferred — Zero Script Blocking
✅ Complete
Google Tag Manager, Google Analytics, and reCAPTCHA used to load on every page visit before anything else — blocking the browser from showing content.
